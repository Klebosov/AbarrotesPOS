Preguntas Frecuentes

¿Se aceptan tarjetas de credito?
Si, aceptamos cualqueir tipo de tarjeta de credito
¿Cuentan con ofertas de forma regular?
Si, todos los fines de semana tenemos ofertas en multiples productos?
¿El sistema permite cobrar con lector de código de barras?
Sí, nuestro sistema es totalmente compatible con la mayoría de escáneres láser y USB del mercado para agilizar las filas.
¿Puedo realizar ventas de productos que no tienen código (como frutas o pan)?
¡Por supuesto! Puedes crear botones de acceso rápido o buscar productos manualmente por nombre para vender artículos a granel o sin etiqueta.
¿Qué pasa si se va el internet mientras estoy cobrando?
El sistema cuenta con un modo offline que permite seguir registrando ventas. Una vez que regrese la conexión, los datos se sincronizan automáticamente.
¿Cómo me avisa el sistema si un producto se está agotando?
Puedes configurar "mínimos de stock". El sistema te enviará una alerta automática cuando un producto llegue a su límite para que realices tu pedido a tiempo.
¿Es posible registrar las mermas o productos caducados?
¡Sí, contamos con un módulo específico para registrar salidas de mercancía por daño o caducidad, manteniendo tu inventario real siempre actualizado.
